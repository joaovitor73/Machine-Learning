# Execução do Projeto Jupyter Notebook

Este projeto utiliza um arquivo `.ipynb` (Jupyter Notebook) que pode ser executado de duas formas:
1. **Google Colab** (recomendado para usuários sem configuração local)
2. **Localmente com Conda** (para usuários que preferem ambiente local)

## Pré-requisitos
- Arquivo do projeto: `framework_para_series_temporais_.ipynb`

---

## 1. Execução no Google Colab (Recomendado para Iniciantes)

### Passo a Passo:
1. **Acesse o Google Colab**  
   Abra [https://colab.research.google.com/](https://colab.research.google.com/)

2. **Faça o Upload do Notebook**  
   - Clique em `Arquivo` > `Upload notebook`  
   - Selecione seu arquivo `.ipynb` no computador

3. **Configure o Ambiente**  
   - Conecte a uma runtime gratuita:  
     Clique em `Conectar` no canto superior direito (usará recursos da Google)
   - Para recursos premium (GPU/TPU):  
     `Runtime` > `Change runtime type` > Selecione o hardware desejado
